## toExpressResponse()

```ts
toExpressResponse(response, res): Promise<void>
```

Adapts a Web Response to an Express Response, invoking appropriate
Express response methods to handle the response.

### Parameters

| Parameter | Type |
| :------ | :------ |
| `response` | [`Response`]( https://developer.mozilla.org/en-US/docs/Web/API/Response ) |
| `res` | `Response`\<`any`, `Record`\<`string`, `any`\>\> |

### Returns

`Promise`\<`void`\>
