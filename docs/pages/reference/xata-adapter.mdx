## Installation

1. Install Auth.js and the Xata adapter

```bash npm2yarn
npm install @auth/xata-adapter
```

2. Install the Xata CLI globally if you don't already have it

```bash npm2yarn
npm install -g @xata.io/cli
```

3. Login

```bash
xata auth login
```
